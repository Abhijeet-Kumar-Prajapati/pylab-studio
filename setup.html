Setup

This website needs nothing. The full Python project needs Python 3.8+.

1. Clone the project

git clone https://github.com/Abhijeet-Kumar-Prajapati/pylab-studio.git
cd pylab-studio

2. Run the console menu

Zero dependencies — only the Python standard library.

run.bat            # Windows
py main.py         # any platform

3. Run the local website (all 132 programs)

py -m pip install flask
run_website.bat
# -> http://127.0.0.1:5001

The local site can execute the real Python programs. This public site runs JavaScript ports of the same algorithms.

4. Optional extras

py -m pip install -r requirements-all.txt

5. Verify

test.bat
py webapp\app.py --selftest     # Total: 132  Passed: 132  Failed: 0
