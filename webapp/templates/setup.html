Setup & download

Everything runs locally. No cloud, no account, no tracking.

1. Requirements

  • Python 3.8 or newer — check with py --version
  • Flask — py -m pip install flask
  • Everything else is standard library

2. Install everything (one command)

setup.bat                         # Windows
py setup.py                       # any platform

Creates a .venv, installs the packages, then verifies every program byte-compiles and runs the full self-test.

Already set up? Just check what is missing: py setup.py --check

3. Start the website

run_website.bat           # Windows, double click
py webapp\app.py          # any platform

Then open http://127.0.0.1:5001

4. Or use the console menu

run.bat

Same programs, straight in the terminal. Press 0 to exit.

5. Verify everything

test.bat                          # compile + smoke test
py webapp\app.py --selftest       # run all {{ stats.total }} programs
