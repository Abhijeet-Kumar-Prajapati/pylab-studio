Design choices

  • Console programs use only the Python standard library
  • Every program has a docstring, input validation and a clean exit
  • The website only runs files from whitelisted folders
  • Each run uses a fresh process, so programs never affect each other
  • A 12 second timeout protects the server from runaway loops
