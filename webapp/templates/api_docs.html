REST API

Base URL http://127.0.0.1:5001. All responses are JSON.

GET /api/programs

Every program in the catalogue ({{ stats.total }} items).

[
  {
    "number": 1,
    "id": "general-absolute",
    "name": "Absolute",
    "category": "Math/Number",
    "description": "Returns the absolute value of a number.",
    "group": "General",
    "path": "programs/general/absolute.py",
    "size_kb": 1.1
  }
]

GET /api/program/<id>

One program by id. Returns 404 if unknown.

curl http://127.0.0.1:5001/api/program/general-area_circle

GET /source/<id> · GET /download/<id>

View the source in the browser, or download a single .py file.

curl -O http://127.0.0.1:5001/download/general-area_circle

GET /export.csv

The whole catalogue as a CSV file.

curl -O http://127.0.0.1:5001/export.csv

POST /api/run

Run a program. Body: {"id": "...", "input": "line1\nline2"}

curl -X POST http://127.0.0.1:5001/api/run \
  -H "Content-Type: application/json" \
  -d '{"id":"general-area_circle","input":"5"}'
{"ok":true,"returncode":0,"stderr":"",
 "stdout":"Radius: Area = 78.5398","seconds":0.05}

GET /api/stats

curl http://127.0.0.1:5001/api/stats

GET /health

curl http://127.0.0.1:5001/health
{"status":"ok","programs":143,"uptime":"0:04:12","time":"..."}
