# Multi Program - All in One: Cheat Sheet

## Run
- `SETUP_AND_RUN.bat` (recommended)
- or `py main.py`

## Menu (type number + Enter, 0 = Exit)
1 Calculator
2 Scientific Calculator
3 Number Tools
4 String Tools
5 Unit Converter
6 Games
7 Statistics Tools
8 File Tools
9 Date & Time / Age
10 JSON Tools
11 Start PayPal Clone Web App (http://127.0.0.1:5000)
12 Environment Check
13 Start Charvis AI (GUI)
14 Start Voice Assistant (Console)
15 Music Library
16 Phone Number Generator (CSV)
17 Toggle Desktop Icons (Windows)
18 Help & Cheat Sheet
0 Exit

## Tips
- Cancel any prompt: type `q`.
- Calculator ops: + - * / // % **
- Trig uses degrees.
- Stats: numbers separated by space or comma.
- Files: use relative or absolute paths.
- Environment check shows missing modules.
