# Multi Program - All in One

## Run the console (all-in-one) program
```
python main.py
```
or
```
run_multi_program.bat
```

## Run the PayPal Clone web app
```
run_web_app.bat
```
Then open http://127.0.0.1:5000

## Notes
- The console program uses only the Python standard library.
- The web app needs the packages in `abhijeet fro/abhijeet fro/abhijeet/venv/Lib/site-packages`.
- `app.py` had trailing pip/console output appended; it has been removed so it runs.
