About

A personal Python project collected into one runnable place.

What this is

132 small Python programs plus two front ends: a console menu and a local Flask website that can execute any program. This public page is the static mirror, with JavaScript ports so the demos work without any installation.

Layout

PathContents

projects/PayPal demo, Charvis voice assistant
learning/, web/, android/Earlier projects

Design choices

  • Console programs use only the Python standard library
  • Every program has a docstring, validation and a clean exit
  • The local site runs each program in a fresh process with a timeout
  • This public site runs entirely in the browser

Runs in your browser. No server, no installation.
