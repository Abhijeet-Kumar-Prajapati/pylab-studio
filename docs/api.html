REST API

Available when you run the project locally: http://127.0.0.1:5001

GET /api/programs

curl http://127.0.0.1:5001/api/programs
[{ "number":1, "id":"general-absolute",
   "name":"Absolute", "category":"Math/Number",
   "description":"Returns the absolute value of a number.",
   "group":"General", "path":"programs/general/absolute.py" }]

GET /api/program/<id>

curl http://127.0.0.1:5001/api/program/general-area_circle

POST /api/run

curl -X POST http://127.0.0.1:5001/api/run \
  -H "Content-Type: application/json" \
  -d '{"id":"general-area_circle","input":"5"}'
{"ok":true,"returncode":0,"seconds":0.04,
 "stderr":"","stdout":"Radius: Area = 78.5398"}

GET /health  ·  /api/stats  ·  /download

curl http://127.0.0.1:5001/health
{"status":"ok","programs":132,"uptime":"0:04:12"}

Limits

  • Input max 4000 characters
  • 12 second timeout per run
  • Only whitelisted folders can execute
  • One process per run
